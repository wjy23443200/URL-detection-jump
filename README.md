# URL 可用性检测中间页

一个无需构建的静态跳转页面。页面样式、目标网址和检测逻辑均包含在 `index.html` 中。

## 工作方式

- 并行加载九个目标网址的 `/favicon.ico`，附加时间戳查询参数以减少缓存影响。
- 每个图标请求的超时时间为 4 秒；通过 `Promise.any` 选择第一个成功加载图标的网址，并在 300 毫秒后跳转。
- 所有图标均加载失败或超时时，页面提示切换网络、刷新或联系客服。
- 在微信、QQ、百度 App 和 QQ 邮箱内置浏览器中，根据 User-Agent 显示“请用浏览器打开”提示，不启动线路检测。

检测结果仅代表目标图标能够加载，不保证目标站点所有页面或服务可用。跨域图片加载不要求目标站点提供 CORS 响应头，但图标缺失或加载被阻止会使对应线路检测失败。

## 使用方法

1. 如需调整线路，编辑 `index.html` 中的 `urls` 数组，填写完整网址。当前配置包含九个网址。
2. 将 `index.html` 部署到静态网站服务器或静态托管服务，无需安装依赖或执行构建。
3. 使用支持 `Promise.any` 的浏览器访问部署后的页面。

当前页面直接跳转到 `urls` 中选中的网址，不传递中间页的路径、查询参数或哈希片段，也不进行 Base64 解码。
